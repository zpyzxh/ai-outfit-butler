## 2. 四条使用路径

**A. 投递（今天就能用）**
1. 用 `01-简历措辞.md` 里对应岗位那一版替换简历里的项目描述（三版不要混用）。
2. 简历附件加 `02-一页技术纸.pdf`（HR 不会看 12 页 PPT，但会看一页纸）。
3. 简历里的项目链接写**演示模式**那个：`https://zpyzxh.github.io/ai-outfit-butler/tryon?demo=1`——点开三下就能看到视频，比裸域名强很多。

**B. 面试前 10 分钟**
1. 翻 `03-面试讲解-12页.pdf`，重点记 4 页：**P02 一页看完 / P04 信息架构 / P07 对照实验 / P09 最贵的 bug**。
2. 手机开演示地址 → 添加到主屏幕（步骤见 `手机演示-扫码卡.png`），确认能秒出结果。
3. 桌面准备：PPT 放映模式（备注在自己屏上）+ 已部署的演示地址。

**C. 面试中（按岗位选讲法）**
| 岗位 | 讲这几页 | 时长 | 收尾钩子 |
|---|---|---|---|
| 前端 | 03 → 04 → 08 → 12 | 5 分钟 | 「主题 token 化让我换肤不动页面代码」 |
| 全栈 | 02 → 05 → 06 → 07 → 09 | 8 分钟 | 「我最贵的一个 bug 花在失败路径上」 |
| 产品 | 02 → 04 → 05 → 03 | 6 分钟 | 「我把最贵的入口位让给了最能打的功能」 |

**D. 手机演示（面试官自己划）**
- 手机浏览器打开 `?demo=1` → 添加到主屏幕 → 从图标进：无地址栏、启动即演示模式（试穿约 5 秒、视频约 2.6 秒）。
- 唯一差异：「把最后一帧存为背面素材」只在 Web 生效，演示模式下已隐藏；微信内置浏览器不支持加桌面，改用 Safari / Chrome。

## 3. 数字口径（三份材料必须一致）

| 指标 | 数字 | 出处 |
|---|---|---|
| 穿搭问答首字 | 3.8s | qwen-plus 实测 |
| 单件试衣出图 | 40–70s | Aidge 同步接口实测 |
| 单张试衣成本 | ¥0.4 | 按供应商单价折算 |
| 一条 5 秒视频 | ¥0.3–0.5 | 万相 i2v 实测 |
| 视频排队最久 | 25 分钟 | 一次真实任务（70s–25min 区间） |
| 客户端代码 | 38 文件 / 7,997 行 TS·TSX | `src/` |
| 边缘函数 | 5 个可部署 / 1,880 行 | `supabase/functions/` |
| 数据库迁移 | 22 个 / 1,151 行 | `supabase/migrations/` |
| RLS 对照实验 | 200 → 403 / 404 | 两个匿名账号 A/B 实测 |
| 演示模式耗时 | 试穿 5s / 视频 2.6s | 预生成样例，0 次 AI 调用 |

**统一规则**：说「实测」的必须是真跑出来的；没跑过的写「设计完成、待验证」，不要四舍五入成「已支持」。

## 4. 投递 checklist

- [ ] 简历项目描述用的是对应岗位那一版（前端 / 全栈 / 产品只留一版）
- [ ] 每条 bullet 都有数字或具体后果，没有「负责」「参与」这类空词
- [ ] 附件 PDF 能正常打开（中文不缺字、图片不糊）
- [ ] 项目链接点开能直接看到结果（用 `?demo=1` 那个）
- [ ] 手机能打开演示地址，且已加到主屏幕
- [ ] 准备一句 20 秒的自我介绍版项目说明（`01` 里的「一句话版」）

## 5. 还没做的（知道边界，别被问倒）

| 项 | 状态 | 被问到时怎么说 |
|---|---|---|
| 原生 APK | 只有 11-15 的旧包，未重打 | 说「原生包要走 EAS 云构建，个人项目没花那个排队时间；现在用 PWA 加桌面，体感接近，而且永远是最新代码」 |
| 真实支付 | 只有 mock 通道 | 说「支付是刻意做成 mock 的，不想碰真钱；换真通道要把验签改成原始字节验签」 |
| 多供应商抽象 | 方案已写、未落地 | 指向 `../后端优化路线图.md` 第 2 节，讲「为什么抽象必须走 CLI 部署」 |
| 一套试穿多件 | 前端串行（每件约 40–70s） | 说「供应商只支持人像 + 单件，我在前端串行叠加，第 N 步拿第 N-1 步结果当输入；后端版本要改成 advance-on-request 规避 Edge 超时」 |
| 匿名用户会累积 | 已知风险 | 说「上限是 MAU 成本和垃圾数据，解法是 90 天未活跃清理 + 恢复码迁移」 |
| 背面视角 | 只能给实物背面图 | 说「商业试衣模型都是单视图；我做的是素材补全——商品补一张背面图，试衣结果里就能『看背面实物图』，比让模型猜背面更可信」 |

> 已上线（2026-11-17）：公网 demo、演示模式、移动端「添加到主屏幕」。
